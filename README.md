## Deploy on a separate GitHub repository
1. Create a new public repository (for example `jatin-akansha-family-functions`).
2. Extract this ZIP and upload `index.html`, `styles.css`, `script.js`, and `ganesha.svg` into the repository root.
3. Go to Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Your existing full-family repository remains unchanged.
